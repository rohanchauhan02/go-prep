# Q09: Nil Interface Trap

## Problem Statement
Demonstrate the classic nil interface trap: a typed nil pointer assigned to an interface is NOT equal to nil. Write a function returning an error interface, show the bug, then fix it.

## Key Concepts
```
interface internals (type+value pair), typed nil, explicit nil return
```

## Requirements
- Solve the problem in `main.go`
- Include example output in comments
- Add unit tests where applicable

## How to Run
```bash
go run main.go
```
