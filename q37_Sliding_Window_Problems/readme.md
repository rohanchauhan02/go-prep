# Q37: Sliding Window Problems

## Problem Statement
Solve three sliding window problems: (1) max sum subarray of size K, (2) longest substring without repeating chars, (3) minimum window substring. All O(n).

## Key Concepts
```
two pointers, freq map, window expand/shrink, character counts
```
