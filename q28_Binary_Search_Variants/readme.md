# Q28: Binary Search Variants

## Problem Statement
Implement 4 binary search variants: (1) exact match, (2) first occurrence, (3) last occurrence, (4) search in rotated sorted array. All must run in O(log n).

## Key Concepts
```
mid calculation overflow, lo<=hi vs lo<hi, rotation pivot
```

## Requirements
- Solve the problem in `main.go`
- Include example output in comments
- Add unit tests where applicable

## How to Run
```bash
go run main.go
```
